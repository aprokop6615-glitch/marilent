# Bows Landing Page

Лендинг интернет‑магазина бантиков ручной работы. Тёплый, дружелюбный дизайн для мам, организаторов фотосессий и тех, кто ищет подарок.

## Что внутри

- `index.html` — главная страница с семантической разметкой (header, main, section, article, footer)
- Стили встроены в `<style>` (можно вынести в `style.css`, если нужно)
- `img/` — папка с изображениями товаров
- Форма заявок на Formspree (заявки приходят на почту)

## Как посмотреть сайт

Сайт публикуется через GitHub Pages. Ссылка формируется автоматически:  
`https://твое-имя.github.io/bows-landing/`  
(замени `твое-имя` на свой ник на GitHub, а `bows-landing` на имя репозитория).

## Как запустить у себя

1. Создай репозиторий на GitHub с именем `bows-landing`.
2. Загрузи туда `index.html`, папку `img` и (если есть) `style.css`.
3. В настройках репозитория (Settings → Pages) выбери ветку `main` и папку `/`.
4. Подожди 1–2 минуты — GitHub Pages развернёт сайт.
